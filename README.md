# AI WORKFLOW

Лендинг курса AI WORKFLOW: шесть экранов (включая программу и доказательства), 12-недельная программа, локальные шрифты Sonko, адаптивная вёрстка и анимации.

Сайт: https://ai-workflow-studio-nov9.arturandreiko.chatgpt.site

## Запуск

Требуется Node.js >=22.13.0.

```sh
npm run install:ci
npm run dev
```

## Сборка

```sh
npm run build
npm start
```

Стек: React 19, Vinext, Vite, Cloudflare Workers. Код страницы находится в `app/`, шрифты и изображения — в `public/`. Настройки существующего сайта Sites — в `.openai/hosting.json`.

Изображения и видео CROX используются как временные материалы по брифу. Видео загружается с исходного CDN. Кнопка записи пока открывает информационное окно: интеграция регистрации не подключена.

Экспорт исходников соответствует опубликованной версии `17cf250d345636249c646a74374dd2267d583988`.
